# e-school
> This is a static e-education web project that represents a school and its services

🌐 LIVE SITE:  https://abrvion.github.io/e-school/

## Overview ✨
This is a static, sleek, modern e-education web project called e-school for an online school, built with a detailed focus on their work and services.

## Features 🎖️
- Modern and sleek web design
- All device responsiveness and design clarity with CSS media queries
- Clean code and reusable blocks
- code commented and easy to maintain
- Psd to Html
- Smooth Animation

## Tech Stack 🚀
- HTML5  
- CSS3
- Bootstrap
